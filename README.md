# Password_generator

📌 Project Overview

A Python-based Random Password Generator that creates secure and customizable passwords based on the user's selected length and character types.

🎯 Objective

To generate random passwords using Python.
To allow users to choose the password length.
To include uppercase, lowercase, numbers, and symbols.
To validate user inputs.
To ensure the generated password contains the selected character types.

⚙️ Project Workflow

User Input → Select Password Length → Select Character Types → Generate Random Password → Display Password

🛠️ Technologies Used

🐍 Python
🎲 Random Module
🔤 String Module
💻 Python IDLE

✨ Features

🔢 Minimum password length of 8 characters

🔠 Uppercase letters
🔡 Lowercase letters
🔢 Numbers
🔣 Symbols
✅ Input validation
🎲 Random password generation
🔐 Ensures each selected character type is included

📊 Result

The program successfully generates a customized random password according to the user's selected length and character types.
